# 已知來源追蹤與未知來源探索

每週一台灣時間 09:17 收集已訂閱來源。另有每日09:47免費到期檢查，不收集、不搜尋、不呼叫模型；每 14 天到期時，另以開放搜尋探索新的工作流、工程概念、工具與實證研究，與目前總覽比較；沒有新 release 仍可進行探索。搜尋結果並非事實認證。

搜尋不限定既有廠商網域。候選資料保留 URL、取得时间、搜尋主題、來源文字及證據狀態。取得原文的候選仍需查核作者與原始發布日期；只有片段時標示片段。相同 URL 去重，但不同作者談相同概念不會被誤稱為多個新工具。

模型在同一批次整理 Android、FDE、工作流更新並提出總覽章節修訂，共用既有付費帳本與每月預算；新增知識總覽不另外開第二次模型呼叫。模型可能回報沒有值得修改的章節。修訂包含理由、來源與原文引用，不能以關注熱度推算市佔率。

graph、loop、harness 不是新近才發明的概念。記錄原始發布日期、最近發現日期與近期能力變化；沒有採用統計就不宣稱「業界都在用」。總覽保留舊版與未重新查核章節的日期。

## 審閱與發布

AI 產生雙週精選、總覽修訂草稿與新來源候選清單，提交公開 PR。候選來源不自動加入永久訂閱；人工核對官方來源及適用性後，才更新 sources 設定。總覽草稿核准後取代網站的目前版本，Git 保留修改紀錄；原始日期研究快照不被覆寫。

審閱未完成、搜尋失敗或模型結果無效時，網站沿用最後核准版。網站「查核日期」不會因每週抓取資料而自動變成今天。核准内容合併 main 後重新建置網站。

## 啟用條件與費用

預設不呼叫搜尋與模型。啟用需要 GitHub Actions Secrets `TAVILY_API_KEY`、`DEEPSEEK_API_KEY`，以及 Variables `KNOWLEDGE_DISCOVERY_ENABLED=true`、`AI_ENABLED=true` 和有效模型價格政策。

每輪最多 6 個 basic 搜尋、每個最多 5 個結果，每月最多 12 次新搜尋預約；實際設定目前為 4 個搜尋主題。搜尋服務 credits 與模型美元預算分別計算，不視為同一帳單。逾時等不確定結果保留預約，不自動重試；需要核對服務帳單並人工處理。

模型預算為每批 US$0.50、每月 US$2，價格持續有效直到手動修改。搜尋與模型均有供應商費用／額度；GitHub repo 是公開的，草稿、候選與保存的來源資料也會公開可見。
